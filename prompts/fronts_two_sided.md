# Two-sided front analysis

## Goals

There are some properties (mainly at the surface) where the front is defined as the location where the property is maximized.  However, there are also cases where the front is defined as the location where the property has large positive/negative (or high/low) values on each side of the front.  This is because the front separates high and low density waters.  We wish to capture this behaviour for a set of the properties when measured at the fronts.

### 2026-06-13 (Prep Task 2: overplot fronts & normalize by Coriolis f)

Added `plot_normalized_vorticity_with_fronts` to
`dev/properties/two_sided/prep_test_region.py`.

- Fronts: `labeled_fronts_global_20121109T12_00_00_V4.npy` is a global
  (12960, 17280) int64 array element-wise aligned with the vorticity
  grid (0 == no front, >0 == labeled front segment).  Memory-mapped it
  (`np.load(..., mmap_mode='r')`) and sliced the same i/j window to
  avoid loading the full ~1.8 GB array.  The test box contains 40
  distinct front labels covering ~3.8% of pixels.
- Overplotted fronts as semi-transparent yellow (alpha=0.4) via a
  `ListedColormap(['yellow'])` layer with non-front pixels masked to NaN.
- Coriolis normalization: used `gsw.f(lat_center)` with the box-center
  latitude (lat=-39.00), giving f=-9.18e-5 s^-1 (single value adequate
  over this ~3 deg box).  Plotted the Rossby number Ro = vorticity / f.
  Used signed f (negative in the S. hemisphere) so positive Ro ==
  cyclonic.  Field spans roughly |Ro| <~ 0.6 at the 99th percentile.

Figure: `dev/properties/two_sided/rossby_with_fronts_test_region.png`.
The yellow fronts trace the strong vorticity filaments / gradients, as
expected for the Brazil-Malvinas confluence.
