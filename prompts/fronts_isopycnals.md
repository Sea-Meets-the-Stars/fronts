## Functionality

- The user will input a 3D density field file, which was generated by the generate_tile script in llc4320-native-grid-preprocessing.
- The user will provide a labeled fronts file which contains the fronts labeled as integers.
- The user will provide a index fronts file which contains the box in i,j (given as x0, y0, x1, y1) for each front.  It also contains a label which is the unique identifier for the front.
- The user will input a density value (kg/m^3) to use to calculate the isopycnal depth.
- The code will calculate the isopycnal depth at each location in the tile.  This will be a 2D field of isopycnal depths.
- The code will generate a figure showing the isopycnal depth at each location in the tile.  It will overlay the location of the fronts on the figure that are within the tile.
- The code will optionally write out the isopycnal depth field to a NetCDF file.  The file will be named isopycnal_depth_tile{tile_index:03d}_{YYYYMMDDTHH}.nc.  The file will be written to the current directory.  If the user provides this file, the code should use it instead of recalculating the isopycnal depth field.

### Plan

#### New module: `dev/rho_and_N/plot_isopycnals.py`

Top-level orchestrator `run(...)` mirroring the pattern in
[plot_top_N_density_profiles.py](../dev/rho_and_N/plot_top_N_density_profiles.py)
(load tile → compute field → write NetCDF → render plot). CLI entry point via
`argparse` so the script can be invoked the same way as its sibling.

CLI flags (proposed):

- `--density-tile`     (required) 3D density tile NetCDF (`sigma0(k,j,i)`).
- `--labels`           (required) Global labeled-fronts integer mask (`.npy` or `.nc`).
- `--front-index`      (required) Front-index parquet (`label, name, x0, y0, x1, y1`).
- `--sigma0`           (required, float) Target potential density in kg m⁻³.
- `--isopycnal-nc`     (optional) Path to a precomputed isopycnal-depth NetCDF. If supplied and exists, the file is read and the calculation step is skipped.
- `--outdir`           (default `.`) Where the PNG (and the NetCDF, if `--write-nc`) are written.
- `--write-nc`         (flag) When set, the isopycnal-depth field is also written to `{outdir}/isopycnal_depth_tile{tile_index:03d}_{YYYYMMDDTHH}.nc`.

#### Algorithm

1. **Load tile metadata** via `_load_density_tile` (moved to `density_utils.py`).
   Lift `tile_index`, `face_index`, `rect_i_start`, `rect_j_start`, `timestamp`,
   plus `sigma0`, `Z`, `XC`, `YC`.
2. **Resolve cached NetCDF**: if `--isopycnal-nc` exists, open it and use its
   `z_isopycnal` variable (must match the tile in shape + provenance attrs);
   otherwise compute step 3.
3. **Compute the isopycnal depth field** `z_iso(j, i)` of shape `(720, 720)`:
   - For each `(j, i)` column, locate the **shallowest** depth where
     `sigma0(z) >= target` (Clarification 4) and linearly interpolate
     between the two bracketing model levels for sub-grid accuracy.
   - Columns where `target` is never crossed — either the surface sigma0
     is already heavier than `target`, or the deepest sample is still
     lighter — are assigned `NaN` (Clarification 3). The colormap's
     "bad" colour will render those pixels distinctly in the plot.
   - Vectorised implementation: for every column, find the first depth
     index `k` such that `sigma0[k] >= target` (e.g. via `np.argmax`
     along the depth axis of the boolean `sigma0 >= target`), guarded by
     a `mask` of columns that never cross. Then linearly interpolate
     between `Z[k-1], Z[k]` weighted by `(target - sigma0[k-1]) /
     (sigma0[k] - sigma0[k-1])`. Pure numpy is sufficient at the
     `(K, 720, 720)` size (~50 MB float32); dask is not used.
4. **Write NetCDF** only when `--write-nc` is supplied (Clarification 2),
   to `{outdir}/isopycnal_depth_tile{tile_index:03d}_{YYYYMMDDTHH}.nc`,
   containing the `z_isopycnal(j, i)` variable, the `XC`/`YC` coords, and
   the same provenance attrs as the input tile plus `target_sigma0`.
5. **Load labeled-fronts tile window** by slicing the global `.npy`/`.nc` on
   the rect grid (`rect_j_start..+720`, `rect_i_start..+720`). Filter the
   front-index parquet to rows whose bbox overlaps that window
   (`_filter_overlapping_fronts`, moved to `density_utils.py`).
6. **Map rect → face-local** with `_build_tile_lookup` so the labels mask is
   re-indexed onto the same `(j_tile, i_tile)` frame as `z_iso`, `XC`, `YC`.
7. **Plot** `imshow(z_iso)` with `cmap='viridis_r'` (deeper = darker reads
   intuitively for depth), `origin='lower'`, colorbar in metres. Overlay
   the labeled fronts as **one continuous outline per front**
   (Clarification 1): iterate over the filtered front labels and call
   `ax.contour(labels_tile_facelocal == label, levels=[0.5], colors='white',
   linewidths=0.7)` for each — this yields a closed outline around every
   front's pixel set without merging neighbouring fronts. Add secondary
   lon/lat axes via the new `_attach_lonlat_twins` helper. PNG name:
   `isopycnal_depth_tile{tile_index:03d}_{YYYYMMDDTHH}_sigma{target:.3f}.png`.
